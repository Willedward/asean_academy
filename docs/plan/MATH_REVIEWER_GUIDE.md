# Mathematics reviewer guide

You review questions at [the review site's content page](https://nextscholar-review-web.onrender.com/admin/content). Solve each question yourself, then approve it or request changes. Students only see content after this review.

## Before you start

You need a Google account with a reviewer role, which William sets up after you sign in and accept an invitation once.

| Role | What you can record |
| --- | --- |
| `academic_admin` | Mathematics and editorial decisions, and publication requests |
| `content_admin` | Editorial decisions only |

Start only with the batches William says are ready. Any change to a question cancels its earlier approvals, so reviewing a batch that is still being fixed wastes your time.

## Review a batch

Work through one batch at a time, because each is only 20–30 questions (diagnostic batches are 4).

1. Open the content page and choose your batch under **Authoring batch**. To review a lesson with its questions, use **Curriculum unit**.
2. Select **Open consolidated reviewer preview**. It shows each prompt, answer, hints, solution, marks, outcome and difficulty.
3. Solve each question before you read its answer, using the checklist below.
4. Deselect every question with a problem, so the rest can be approved together.
5. Choose **Mathematics** or **Editorial**, then **Approve selected**. Add a note on what you checked, confirm, and record the session.
6. For each deselected question, select **Open reviewer preview**, choose **Request changes**, and write what is wrong.
7. Select **Open correction export** and send the result to William. Corrected questions come back as new revisions for you to review again.

A question needs both a Mathematics and an editorial approval. After that, an `academic_admin` selects **Review publication request**. This only records the request, and publishing still happens through a separate release.

You can't edit a question on this page, because corrections are made in the source files. If a screen differs from these steps, tell William.

## What to check on every question

Request changes if the answer to any of these is no. Students are about 14–15, are preparing for Secondary 3 entry, and are tested at Secondary 1 and 2 level.

| Check | What to ask yourself |
| --- | --- |
| Answer | Does your own answer match the key, and does it fit the original conditions? |
| One answer | Is exactly one answer defensible? For numeric codes, could a second code also be right? |
| Complete | Does the question give everything needed, without anything contradictory? |
| Solution | Is every step correct, and does it use a method the lesson teaches? |
| Hints | Do they help without giving the answer? |
| Diagram | Does it match the givens, and is it free of the answer? Could it be text-only? |
| Marking | Would a correct answer in another reasonable form be accepted? Is rounding stated? |
| Scope | Is it within Secondary 1–2 and its stated outcome, with the right difficulty? |
| Wording | Is it clear to a student learning English, with a sensible context? |

Also check for leaks in the prompt and worked examples, and tell William about anything you can't test from the preview.

## Don't flag these

These are decisions William has already made, so they are not errors. Tell William if you think one is wrong.

- **Money:** written as S$.
- **Language:** British spelling and Singapore syllabus terms, with a short explanation the first time a term is used.
- **Topics kept in scope:** area and volume scale factors, and standard form. Other out-of-syllabus topics should be rewritten, so please flag those.
- **Numeric codes:** students may answer with a code, such as "1 for a dot diagram", as long as only one code is defensible.
- **Hints:** at difficulty 1–2 a second hint may show the full operation. At difficulty 3 and above it must not give the result or a value that ends the task.
- **Answer form:** form is only enforced where the prompt asks for it, such as "expanded form". To 3 significant figures, `3.33` is right and `3.333` is wrong.
- **Unreadable answers:** an answer like `3,8` doesn't count as wrong, because the student is asked to fix it.

These known issues are planned for a later pass, so you don't need to report them:

- Duplicate or very similar questions.
- Repeated, template-style contexts.
- Odd names in some Sec 2 titles, such as "Jade Orchid Bay".

## Writing a useful correction

A good note says what is wrong, how you know, and what you'd change, because the fix is made from your words alone.

| Instead of | Write |
| --- | --- |
| Wrong answer. | Key is 7, but I get 5: the line in the graph passes through (0, 0), not (0, 4). Either redraw the line or change the key. |
| Confusing. | "Least suitable" could mean two of the displays. Name the data range so that only a dot diagram fits. |
| Hint is bad. | Second hint gives 90, which ends the task at difficulty 3. Stop at "the angles around the point add to 360°". |

When you approve a batch, note what you did, such as "Solved all 26 myself and checked solutions and diagrams." This is kept as the permanent record, and every decision is saved with your name.

If you find the same problem across many questions, tell William once with a few examples rather than repeating the note.
